# Governance

Keepsake Scanner is a maintainer-led open-source project.

## Roles

- Contributors propose issues, documentation, code, tests, and reviews.
- Reviewers provide recurring, constructive review in an area of the project.
- Maintainers manage releases, security reports, repository settings, and final merge decisions.

Roles are earned through sustained, respectful contributions. Maintainers may invite additional reviewers or maintainers when the project needs broader ownership.

## Decisions

Routine decisions happen in issues and pull requests. Maintainers seek consensus for user-facing behavior, privacy, compatibility, and architecture. When consensus is not possible, the active maintainers make a documented decision based on project goals, security, maintainability, and user impact.

## Project values

1. Local-first privacy
2. Safe handling of irreplaceable photographs
3. Clear and reversible user actions
4. Portable source code with no contributor environment data
5. Accessible internationalization
6. Evidence-based scanner compatibility
