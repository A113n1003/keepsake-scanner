# Asset Provenance

## Synthetic demo scan

`resources/demo-flatbed.png` and the four files in `resources/demo-crops/` were created specifically for Keepsake Scanner on 2026-07-26 with an image-generation tool.

Prompt summary: a top-down flatbed containing exactly four fictional vintage prints—an alpine lake, a wooden toy train, wildflowers, and a bicycle by the sea—with no people, names, readable signs, brands, documents, or watermarks.

The crop files are deterministic outputs of the project’s native separator. The assets are distributed with the project under the MIT License.

## Application icon

The scanner-and-landscape application icon is original project artwork, contains no people or third-party brand marks, and is distributed with the project under the MIT License.

## Privacy review

Binary assets require human review because source scanners cannot detect private information rendered into pixels. Every public asset in this repository has been reviewed for people, personal documents, local paths, names, addresses, and device identifiers.
