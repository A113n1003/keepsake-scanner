# Support

## Questions

Use GitHub Discussions for setup questions, workflow ideas, and community help.

## Bugs

Open a bug report and include the minimum sanitized information requested by the template. Search existing issues first.

## Security and privacy

Use the private process in [SECURITY.md](SECURITY.md). Never post real scans, private metadata, scanner identifiers, credentials, or local user paths in a public issue.

## Scope

Community support is best-effort. Scanner behavior depends on macOS Image Capture and vendor drivers, so not every device can be reproduced by maintainers.
